# danse-test (essai séparé, hors machine à vidéo)

Loup musclé style avatar Roblox qui danse sur le faîte d'un toit, caméra en orbite 360° continue,
fondu au noir au début et à la fin, ~17 s, 76 BPM, sans audio.

- `web/scene.js` : décor (toits à studs, île, océan, tour, avatars volants), perso riggé, chorégraphie, caméra.
- `node render.js test 1,4.5,8` : images de test dans `out/`.
- `node render.js full 17.28` : `out/danse.mp4` (rendu 720×1280, livré en 1080×1920).
